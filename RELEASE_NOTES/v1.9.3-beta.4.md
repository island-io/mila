# Mila 1.9.3-beta.4

- **Set up Claude with one button — no Terminal.** Settings → AI Provider can now install Anthropic's official Claude CLI for you: Mila downloads it, checks its Apple code signature before ever running it, opens your browser to sign in with your Claude subscription, and keeps the credential in your Keychain. A Test button proves the whole path works. If you already have the Claude CLI installed, Mila now says so — "Using your Claude CLI" in green — instead of showing "Not set up".
- **Voice profiles now fix themselves when you fix the transcript.** Un-naming, renaming, or merging a speaker corrects what Mila learned from that voice instead of leaving the old lesson in place. Naming a speaker mid-recording now creates a voice profile too, and a speaker renamed by a re-diarization no longer silently loses the recognition weight it had earned. (Cross-recording voice recognition stays opt-in and off by default.)
- **The live transcript is editable while you record.** Delete an individual line and it is gone for real — the Live AI assistant forgets it too, so a deleted line cannot resurface in a summary. There is also a copy-transcript button next to the SRT export.
- **Pick a folder and a meeting name when you start recording.** New recordings can be filed and titled up front instead of renamed afterwards.
- **Google Meet is detected in Chrome, Safari, Arc, and Island.** Meeting-start prompts are no longer Zoom-only.
- **AI summaries are more dependable.** Action items are back on the one-shot summary; the live assistant waits for speaker names to be final before reading a line, so summaries stop saying "Speaker 2"; and leftover working files are cleaned up between sessions.
- **Fixed AI actions reporting a timeout for commands that had already finished.** A thread-pool starvation bug could leave a completed command waiting to be noticed until Mila gave up. Blocking waits now run on dedicated threads.
- **Quieter, safer logs.** Recording titles, file paths, and subprocess output no longer appear in the public fields of the unified log, and the new Claude sign-in redacts the credential everywhere, always.
- **Transcript search over MCP is faster and bounded.** Relevance scoring works from raw segments instead of rendering every transcript, and a single search call can no longer read an unbounded amount of the store.
- **Turning diarization off mid-recording now takes effect immediately.** Stored-voice matching stops on the spot instead of continuing through the rest of the recording.
