# Mila 1.9.9

**New**

- **Antigravity as an AI provider.** Settings → AI Provider now offers Antigravity (the `agy` command-line tool).

**Fixes**

- **Long recordings on a remote transcription server now finish.** Recordings longer than the server accepts in one request are sent in pieces, split at pauses in speech, and stitched back into one transcript. When transcription does fail, the recording shows "Transcription failed" with the reason, instead of a blank transcript.
- **The end of a recording is no longer cut off.** Transcription could miss up to the last 64 ms of a recording, and its saved length came out slightly short. Every frame is now read.
- **Mila no longer quits when the microphone changes format as recording starts.** This could happen when you started recording during a call on AirPods, as they switched to their call mode. Mila now retries with the new format. If that also fails, you see an error message instead of the app closing.
- **A damaged recordings list no longer wipes your library.** Previously, if Mila couldn't read its list of recordings at launch, it treated the library as empty and saved over the list. Now it keeps every entry it can read and saves a backup copy of the damaged file. It also brings back any recording whose audio is still on disk, and shows a banner explaining what happened.
- **Dictation never pastes into a locked screen.** If your Mac locks or sleeps while dictated text is being transcribed, the text is no longer pasted or put on the clipboard. Pressing the dictation hotkey twice in quick succession no longer runs it twice. If the microphone gets stuck shutting down, dictation still pastes what you said and keeps working.
- **Speaker detection setup is more reliable when you use your own Python.** Mila installs versions of pyannote and torch that are known to work together. It now tells you plainly when your Python version isn't supported (3.9–3.12 are). Setup steps that stall now time out instead of hanging forever.
- **Transcription no longer holds up the rest of the app.** A long transcription used to tie up one of the threads the rest of Mila shares, so speaker detection and other background work queued behind it.
- **Mila no longer crashes at launch** if macOS can't locate its Application Support folder.

**Faster**

- **Editing a large library no longer freezes the app.** Renaming, moving and restoring recordings now save in the background, and the library file is written more compactly.
- **Faster launch with a large library.** Transcripts are read in parallel at startup.
- **Less memory during transcription.** Long recordings are no longer copied while being prepared for Whisper, which saves hundreds of megabytes on an hour of audio.
- **Less memory when you don't transcribe while recording.** With Transcribe while recording off, Mila no longer keeps the Whisper model loaded while idle. It loads the model when there is something to transcribe and frees it afterwards. Dictation starts loading the model as soon as you press the hotkey, so your text is ready about as quickly as before.
