# Mila 1.9.3-beta.1

- **Remote transcription now works with OpenAI's newer speech models.** Mila always asked its transcription server for `verbose_json`, the format that carries word timings — and the `gpt-4o-transcribe` family rejects it, along with every other timestamped format. That silently limited remote transcription to `whisper-1`. Mila now picks the format each model actually accepts, so the newer models work, and `gpt-4o-transcribe-diarize` can return speaker labels straight from the server. Self-hosted servers are unaffected and keep their word timings.
- **Mila no longer leaves a folder behind in `~/.claude` after every AI summary.** Each call to the Claude CLI ran in a throwaway directory, and the CLI files its conversation history under a name derived from that directory — so every summary, title and action-items run created a new project folder that nothing cleaned up, and whose transcript couldn't be reopened because Mila had deleted the folder it was named after. All AI calls now share one directory, so there's one project instead of hundreds, and those conversations are resumable. Existing leftovers are harmless and can be removed with `rm -rf ~/.claude/projects/*island-mila-llm-*`.
- **Undo works in the Settings prompt editors.** "Reset to default" and picking an Example each replaced a prompt you'd written by hand, instantly and with no way back — ⌘Z did nothing. Those overwrites now go on the same undo stack as your typing, so ⌘Z steps back through them one at a time, and an **Undo** link appears in the editor while there's something to undo.
