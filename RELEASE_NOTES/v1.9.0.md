# Mila 1.9.0

The first stable release of the 1.9.0 line — a big one, with everything since 1.8.14.

## New

- **Transcribe on a remote server.** Point Mila at any OpenAI-compatible API — OpenAI's Whisper, or your own self-hosted model like ivrit.ai — instead of transcribing on-device. Set it up in Settings → Models. **Test connection** now uploads a short sample clip and shows you the text that comes back, so you can confirm the server actually transcribes (not just that it's reachable).
- **One-click setup with `.milaconfig` files.** Double-click a `.milaconfig` file and Mila offers to apply it — the transcription server, model, language, and more — after showing you exactly what will change. Perfect for handing a team a ready-made configuration. Settings not named in the file are left untouched.
- **iPhone Voice Memos sync.** Mila can import and auto-transcribe the Voice Memos that iCloud syncs from your iPhone. Pick which folders to watch, set a start date so it doesn't backfill years of old recordings, and it files them under a dedicated **Voice Memos** folder. It only needs access to that one folder — no Full Disk Access.
- **Name your speakers.** Rename speaker labels to real names from a persistent, searchable directory — your names are remembered and reused across recordings.
- **Opt into betas.** A new Settings → Updates tab lets you enable pre-release builds and move back to stable whenever you like.

## Transcription quality

- **Fewer hallucinations.** A neural voice-activity detector skips non-speech, so Whisper stops inventing filler text on silence or background noise.
- **Better with quiet built-in mics.** Adaptive gain boosts low-volume input so live transcription keeps working on soft laptop microphones.
- **Auto-discard accidental clips.** Very short recordings with no speech — hotkey misfires, empty captures — are dropped automatically. Tune the threshold (or turn it off) in Settings → Storage.

## Queue & recordings

- **Stop or remove Queue items.** Cancel a stuck or unwanted transcription right from the Queue. Stopped items move to Recently Deleted instead of showing up as "Failed."
- **No more stuck "Queued" items** after you quit and relaunch mid-transcription.
- **The Record button no longer waits** on the final summary of your previous recording — start the next one immediately.
- **A color per speaker** when speaker labels are on, so who-said-what is easier to scan.
- **Export SRT subtitles mid-recording** from the live transcript.
- Collapsible "All Transcriptions" section in the sidebar.

## AI & summaries

- **Automatic summaries** after each recording (toggle in Settings → LLM), a configurable CLI timeout, and a Test panel to debug your LLM setup.

## Fixes & reliability

- A large bug-fix sweep across the transcription engine, audio capture, diarization, and UI, with new regression tests.
- System audio is no longer dropped when its clock stalls; the diarization setup no longer gets stuck in a repair loop.
- Locally-built and DMG installs preserve their signing identity so macOS permission grants (mic, screen recording) survive updates.
- Fixed the stray border around the dictation pill, restored the sidebar's right-click menu, and many smaller fixes.
- Added CodeQL security scanning to every build.
