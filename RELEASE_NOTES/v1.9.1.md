# Mila 1.9.1

- **Notes for one meeting stay with that meeting.** The Live AI pane now has its
  own **Context** box for things you want Mila to know about the meeting you're
  in — the agenda, who's on the call, acronyms it won't recognise. Mila uses
  them to understand what it hears, never summarises them, never turns them into
  action items, and clears them when the recording stops. Previously the only
  place to put that was the system prompt in Settings → Live AI, which applies
  to *every* recording — so one meeting's agenda quietly became the next
  meeting's context, and the summary came back covering both.
