# Mila 1.9.3

The stable release of everything in the 1.9.3 betas, plus the model-management fixes that came out of testing them.

**New**

- **Set up Claude with one button — no Terminal.** Settings → AI Provider can install Anthropic's official Claude CLI for you: Mila downloads it, checks its Apple code signature before ever running it, opens your browser to sign in with your Claude subscription, and keeps the credential in your Keychain. A Test button proves the whole path works. If you already have the Claude CLI installed, Mila says so — "Using your Claude CLI" in green — instead of showing "Not set up".
- **Mila can recognise the same speaker across different recordings, if you turn it on.** Once you name a speaker, Mila can remember that voice and label them automatically in later recordings instead of asking again every time. It is off by default; enable it under Speakers in Settings, where you can also delete everything Mila has learned at any point — including while the feature is switched off.
- **Voice profiles fix themselves when you fix the transcript.** Un-naming, renaming or merging a speaker corrects what Mila learned from that voice instead of leaving the old lesson in place. Naming a speaker mid-recording creates a profile too, and a speaker renamed by a re-diarization no longer silently loses the recognition weight it had earned.
- **Mila can hand your transcriptions to AI tools, if you turn it on.** A new `mila-mcp` server exposes your recordings and transcripts over MCP, so tools like Claude Code can search and read them without you copying text around. It is off by default and gated behind an explicit consent step — nothing is readable until you enable it, revoking access takes effect immediately, and recordings you have moved to the trash stay unreachable.
- **The live transcript is editable while you record.** Delete an individual line and it is gone for real — the Live AI assistant forgets it too, so a deleted line cannot resurface in a summary. There is also a copy-transcript button next to the SRT export.
- **Pick a folder and a meeting name when you start recording**, instead of renaming afterwards.
- **Google Meet is detected in Chrome, Safari, Arc and Island.** Meeting-start prompts are no longer Zoom- and Teams-only.
- **Settings uses a sidebar instead of a row of tabs.** The tab strip had run out of room, so sections now live in a sidebar that stays readable as more get added.

**Models and disk space**

- **Deleting a model now sticks.** Settings → Models → Delete removed the file, but Mila's launch check only asked whether the file was there — it could not tell "never downloaded" from "deleted on purpose", so the next launch quietly downloaded it again. Since an update is just a fresh start, that meant a multi-gigabyte download coming back after every update. A deleted model now stays deleted until you ask for it again.
- **Deleting a model frees all the space Mila said it would.** Each model has a companion CoreML encoder of about 1.1 GB that was left behind, with nothing in the app able to see or remove it — so the confirmation dialog promised more than you got. Both parts are now removed together, and the dialog quotes the real figure.
- **Deleting both models no longer leaves Mila stuck.** Every recording afterwards failed with "Whisper model is still downloading. Try again once it's ready." — which was never going to become true, and never mentioned the way out. Mila now tells you the model was deleted and points you at Settings → Models.
- **Your chosen model stays chosen.** Mila re-applied its own default on every launch, quietly overriding what you picked in Settings → Models.

**Transcription**

- **Remote transcription works with OpenAI's newer speech models.** Mila always asked for `verbose_json`, the format that carries word timings — and the `gpt-4o-transcribe` family rejects it, which silently limited remote transcription to `whisper-1`. Mila now picks the format each model actually accepts, and `gpt-4o-transcribe-diarize` can return speaker labels straight from the server. Self-hosted servers are unaffected and keep their word timings.
- **Remote transcription models are picked from a known-good list**, instead of typed by hand and failing mid-transcription.
- **Re-transcribing a recording no longer confuses what Mila has learned about a voice.** Re-running a transcription cleared the speaker names it had just re-keyed, which left the voice Mila learned from that recording attached to nothing — you could not undo it, and the same recording could be counted twice. Re-transcribing now re-attaches each name to the voice it already taught.
- **Turning diarization off mid-recording takes effect immediately**, rather than continuing through the rest of the recording.

**Fixes**

- **AI actions no longer report a timeout for commands that had already finished.** A thread-pool starvation bug could leave a completed command waiting to be noticed until Mila gave up.
- **AI summaries are more dependable.** Action items are back on the one-shot summary; the live assistant waits for speaker names to be final before reading a line, so summaries stop saying "Speaker 2"; and leftover working files are cleaned up between sessions.
- **Mila no longer leaves a folder behind in `~/.claude` after every AI summary.** All AI calls now share one directory, so there is one project instead of hundreds, and those conversations are resumable. Existing leftovers are harmless and can be removed with `rm -rf ~/.claude/projects/*island-mila-llm-*`.
- **Undo works in the Settings prompt editors.** "Reset to default" and picking an Example each replaced a hand-written prompt with no way back. Those overwrites now go on the same undo stack as your typing.
- **Mila finds the Claude CLI when npm is set up with a custom prefix**, including from `.npmrc`, instead of reporting "CLI not found".
- **The Send action points the AI at the transcript file instead of pasting it**, so long transcripts are available in full.
- **Transcript search over MCP is faster and bounded.** Relevance scoring works from raw segments instead of rendering every transcript, and a single search call can no longer read an unbounded amount of the store.
- **Quieter, safer logs.** Recording titles, file paths and subprocess output no longer appear in the public fields of the unified log, and the Claude sign-in redacts the credential everywhere, always.
- **Every AI CLI invocation is written to the unified log**, so a failed summary or title is diagnosable instead of guesswork.
